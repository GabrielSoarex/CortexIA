## 🎯 Objetivo do Projeto
O **CortexIA** é uma aplicação desktop que permite aos colaboradores abrir chamados de suporte técnico.  
Os chamados são analisados por uma IA para **sugerir soluções imediatas** ou encaminhar ao técnico responsável.  
O sistema também permite acompanhamento dos chamados, registro de soluções e **geração de relatórios gerenciais**.
