## 🎯 Objetivo do Projeto
O **CortexIA** é uma aplicação desktop que permite aos colaboradores abrir chamados de suporte técnico.  
Os chamados são analisados por uma IA para **sugerir soluções imediatas** ou encaminhar ao técnico responsável.  
O sistema também permite acompanhamento dos chamados, registro de soluções e **geração de relatórios gerenciais**.

## 🛠️ Tecnologias e Linguagens do Projeto

**Frontend**

- **JavaScript** – como linguagem principal.
- **Nuxt.js e Vue.js ** –para construção do SPA e gerenciamento de rotas/componentes.
- **Vuetify** – para estilização e componentes prontos, garantindo consistência visual.
- **HTML e CSS** – para customização adicional e criação de layouts personalizados.

**Backend**

- **Java** – (Spring Framework) para lógica de negócios, processamento de chamados e integração geral do sistema.
- **C#** –API em  específica para geração de relatórios, permitindo separação de responsabilidades e flexibilidade tecnológica.

**Mobile**

- **Dart** – como linguagem principal.
- **Flutter** –  para desenvolvimento de aplicativo móvel multiplataforma (Android e iOS), integrando funcionalidades do sistema.

**Banco de Dados**

- **MySQL** – Para armazenamento de informações de usuários, chamados, soluções registradas e histórico de atendimentos.
